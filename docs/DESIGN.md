# 내 리밸런싱 보드 · 디자인 가이드라인

기준 시안: `reference/rebalance-board.html`. 이 문서와 시안이 다르면 시안의 실제 모양을 따르고, 이 문서를 고친다.

## 1. 원칙

1. **판단이 먼저, 숫자는 그다음.** 화면을 열면 "지금 손댈 필요가 있는가"가 3초 안에 보여야 한다. 상태 알약과 막대 색이 그 역할을 한다.
2. **장부처럼 조용하게.** 장식, 그림자, 그라데이션, 이모지를 쓰지 않는다. 강조는 색 하나와 굵기로만 한다.
3. **숫자는 줄이 맞아야 한다.** 금액·수량·비율은 모두 고정폭 글꼴과 오른쪽 정렬을 쓴다.
4. **색만으로 말하지 않는다.** 상태는 색과 함께 글자(양호 / 주의 / 리밸런싱 필요, 매수 / 매도)로도 적는다.
5. **폰이 기준이다.** 폭 400px에서 먼저 확인하고 넓은 화면으로 늘린다.

### 2.5 테마 적용 방식

세 가지 상태를 모두 처리한다.

```css
:root { /* 라이트 값 전체 */ }
@media (prefers-color-scheme: dark) {

}
:root[data-theme="dark"] { /* 같은 다크 값 */ color-scheme: dark; }
```

## 4. 배치

- 본문 최대 폭 880px, 가운데 정렬.
- 좌우 여백은 최소 16px. `max(16px, env(safe-area-inset-left))` 형태로 쓴다.
- 패널 사이 20px, 패널 안 요소 사이 12px, 패널 안쪽 여백 16px.
- 간격은 flex/grid의 `gap`으로 준다. 요소마다 margin을 따로 주지 않는다.
- 모서리 반경: 패널·요약 10px, 카드·안내 상자 8px, 입력칸·버튼 6px, 태그 4px, 알약 999px.
- 그림자는 선택된 탭의 아주 옅은 것 하나뿐이다. 다른 곳에 쓰지 않는다.
- 표는 폭 540px 이하로 줄어들지 않는다. 좁은 화면에서는 표를 감싼 영역만 가로로 스크롤한다. 페이지 전체가 가로로 밀리면 안 된다.

| 보유 자산 카드 | 12칸 격자 2줄 | 칸을 넓혀 4줄 |

## 5. 컴포넌트

### 5.1 탭
- 탭 묶음은 `--sunk` 바탕에 4px 안쪽 여백, 반경 9px.
- 선택된 탭만 `--surface` 바탕과 `--fg` 글자. 나머지는 `--muted`.
- 순서 고정: 대시보드 / 포트폴리오 / 보유 자산.

### 5.2 요약 4칸
- 칸 사이는 1px 선(바탕 `--line`에 gap 1px).
- 각 칸: 라벨 → 큰 숫자 → 한 줄 보조 설명.
- "상태" 칸은 숫자 대신 알약을 넣는다.

### 5.3 상태 알약
- 앞에 7px 원, 뒤에 글자. 글자색과 원 색이 같고 바탕은 soft 색.
- 문구는 세 가지뿐이다: 양호 / 주의 / 리밸런싱 필요.

### 5.4 비중 막대 (이 화면의 핵심 요소)
한 행은 네 겹으로 구성한다.

1. 트랙: 높이 22px, `--sunk`, 반경 4px
2. 허용 밴드: 목표 ± 밴드 구간을 `--accent-soft`로 칠함
3. 현재 비중 막대: 왼쪽에서부터 채움
4. 목표선: 폭 2px, 트랙보다 위아래로 3px씩 길게, `--target`

막대 색은 이탈 크기로 정한다.

| 이탈(절댓값) | 막대 색 | 수치 색 |
|---|---|---|
| 밴드 절반 이하 | `--accent` | 초과면 `--warn`, 부족이면 `--accent` |
| 밴드 이하 | `--warn` | 위와 같음 |
| 밴드 초과 | `--bad` | `--bad`, 굵게 |

- 가로축 최댓값은 (가장 큰 현재 비중, 가장 큰 목표 + 밴드) 중 큰 값의 1.08배. 최소 10%.
- 오른쪽 수치: 첫 줄 `현재% / 목표%`, 둘째 줄 `+1.2%p` 형식의 차이.
- 대표 종목형 그룹의 소속 종목은 밴드와 목표선 없이 반투명 막대만 그리고 "그룹명 합산"이라고 적는다.
- 범례(현재 비중 / 허용 밴드 / 목표)를 패널 제목 오른쪽에 둔다.
- 스크린 리더용으로 트랙에 `role="img"`와 "종목명 현재 x%, 목표 y%" 라벨을 넣는다.

### 5.5 표
- 머리글: 0.72rem, `--muted`, 굵기 600, 아래 1px 선.
- 첫 열(종목명)은 왼쪽 정렬·본문 글꼴. 나머지는 오른쪽 정렬·Mono.
- 종목명 아래에 작은 줄로 "그룹 · 계좌 · 1주 가격"을 적는다.
- 합계 행은 위에 1px 선, 굵기 600.
- 줄무늬 배경은 쓰지 않는다.

### 5.6 매매 태그
| 태그 | 글자색 | 바탕 |
|---|---|---|
| 매수 / 입금 | `--ok` | `--ok-soft` |
| 매도 / 출금 | `--bad` | `--bad-soft` |
| 유지 / 이번 달 보류 | `--muted` | `--sunk` |

태그 뒤에 수량을 Mono로 붙인다. 예: `매수 12`.

### 5.7 안내 상자
- 기본: `--sunk` 바탕, 반경 8px, 0.86rem. 표 아래에서 결과를 한두 문장으로 요약한다.
- 경고: `--warn-soft` 바탕. 대시보드 맨 위에만 둔다.
- 문장 안의 숫자는 Mono + 굵기 600.

### 5.8 입력
- 입력칸·선택칸: `--bg` 바탕, 1px `--line` 테두리, 반경 6px, 안쪽 여백 8px 10px.
- 라벨은 입력칸 위에 0.78rem `--muted`.
- 단위(%, 비율)는 입력칸 오른쪽 안쪽에 겹쳐 표시한다.
- 포커스: 2px `--accent` 외곽선. 없애지 않는다.
- 읽기 전용 값(종목코드, 현재가)은 입력칸 모양으로 그리지 않는다. 라벨 + 값 글자로만 보여 준다.

### 5.9 버튼
| 종류 | 모양 | 쓰임 |
|---|---|---|
| 주 버튼 | `--accent` 바탕, `--surface` 글자 | 그룹 추가, 체결 반영, 반영 |
| 보조 버튼 | `--surface` 바탕, 1px 테두리 | 가격 새로고침, 취소 |
| 삭제 | 테두리 버튼에 ✕, `--muted` | 종목·그룹 삭제 |
| 글자 버튼 | 밑줄, `--accent` | "직접 입력", "되돌리기" |

한 패널에 주 버튼은 하나만 둔다.

### 5.10 그룹 카드 (포트폴리오 탭)
- `--bg` 바탕, 1px 테두리, 반경 8px.
- 머리 줄: 색 점 · 그룹 이름 입력 · 현재 비중 · 목표 % 입력 · 삭제.
- 규칙 줄(종목 2개 이상일 때만): 규칙 선택, 대표 종목형이면 "매수"와 "먼저 매도" 선택.
- 종목 행: 위 1px 선으로 구분. 이름 아래에 그룹 이동 선택과 "계좌 · 상장구분".

### 5.11 종목 검색
- 검색칸은 다른 입력보다 크게(1rem, 안쪽 여백 10px 12px).
- 필터 칩: 알약 모양. 선택되면 `--accent` 바탕.
- 결과 목록: 최대 높이 340px, 안에서 세로 스크롤. 행마다 이름 / "상장구분 · 코드 · 시총" / 자산군 칩.
- 이미 보유한 종목은 `--ok` 색 "보유 중"을 붙인다.

### 5.12 자산군 칩
- 글자색은 해당 `--k` 색, 바탕은 같은 색의 15% 투명도(`color-mix`).
- 0.7rem, 굵기 600, 반경 4px.

## 7. 문구

- 사용자가 아는 말을 쓴다: "그룹", "보유 자산", "이월 현금". 내부 용어(unit, doc, sync)를 화면에 내지 않는다.
- 버튼은 누르면 일어나는 일을 그대로 적는다: "체결 반영", "그룹 추가", "가격 새로고침".
- 안내는 "무엇이 어떻게 됐고, 무엇을 하면 되는지"를 한두 문장으로 쓴다.
  - 좋은 예: "매수 후 최대 이탈은 2.1%p → 0.4%p입니다. 남는 현금 23,877원은 다음 달 이월 현금으로 넘어갑니다."
- 오류는 사과 없이 원인과 해결을 적는다.
  - 좋은 예: "가격을 찾지 못한 자산은 평균단가로 계산했습니다: QQQM."
- 매매를 권하는 말투를 쓰지 않는다. "사세요" 대신 "매수 12"처럼 계산 결과로 적는다.
- 느낌표와 이모지를 쓰지 않는다.

## 9. 움직임

- 막대의 폭과 목표선 위치만 0.25초로 부드럽게 바뀐다.
- `prefers-reduced-motion: reduce`이면 움직임을 모두 끈다.
- 그 밖의 등장 효과, 숫자 올라가는 효과는 넣지 않는다.

## 10. 접근성

- 모든 입력에 라벨 또는 `aria-label`이 있어야 한다.
- 탭은 `role="tablist"` / `role="tab"` / `aria-selected`를 쓴다.
- 누를 수 있는 요소는 폰에서 높이 38px 이상.
- 글자와 바탕의 명도 대비는 본문 4.5:1 이상. 색 토큰을 바꾸면 라이트·다크 모두 다시 확인한다.

## 11. 하지 않는 것

- 원 그래프·도넛 그래프. 목표 대비 차이가 보이지 않는다.
- 카드마다 그림자와 큰 반경.
- 상승을 초록, 하락을 빨강으로 표시(미국식). 이 화면은 한국 관례를 따른다.
- 화면을 가리는 팝업과 브라우저 기본 확인창. 확인은 화면 안의 패널로 한다.
- 외부 아이콘 묶음. 필요한 기호는 글자(✕, ▲)로 충분하다.
